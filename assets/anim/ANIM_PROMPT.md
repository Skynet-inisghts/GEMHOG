# Промпт для Claude Code — анимация в хиро

Папку `anim/` положи в репо как `assets/anim/`. Дальше в Claude Code:

---

Заменяем статичную свинью в хиро-панели (`assay bench / sniffing for stones`) на зацикленную анимацию: свинья нюхает, зарывается в грязь, находит алмаз, алмаз уходит обратно в землю, цикл повторяется.

Материал в `assets/anim/`:
- `gemhog-dig-sheet.png` — спрайтшит, 32 кадра по 104×96 нативных пикселей в ряд
- `gemhog-dig.css` — готовые keyframes: `steps(32)`, 90 мс на кадр, `image-rendering: pixelated`, масштаб через `--px`
- `gemhog-dig.apng` / `.gif` — то же самое одной картинкой, на случай если спрайтшит неудобен
- `render_anim.py` — источник; если понадобится другой размер или палитра, правится там

Что сделать:
1. Скопировать спрайтшит в `public/gemhog-dig-sheet.png`, keyframes перенести в `app/globals.css` (или CSS-модуль хиро), путь в `background: url(...)` поправить на `/gemhog-dig-sheet.png`.
2. В хиро вместо `<img>` со свиньёй поставить `<div class="gemhog-dig" aria-label="Gemhog digging for a stone" role="img" />`. Масштаб подобрать так, чтобы высота совпала с текущей картинкой (сейчас ~520px → `--px: 6` или `7`, целое число, иначе пиксели поплывут). На мобильном `--px: 4`.
3. `prefers-reduced-motion` уже учтён в CSS — показывается кадр с камнем во рту. Не ломать.
4. Нигде не масштабировать через `transform: scale()` с дробью и не включать сглаживание — только `image-rendering: pixelated` и целый `--px`.
5. Тот же спрайтшит использовать как лоадер на `/terminal`, пока считается грейд: тот же класс, `--px: 3`, рядом текст `sniffing…`. После ответа — сертификат.

Покажи хиро и лоадер скриншотами.
